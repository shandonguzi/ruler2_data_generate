分类与迭代

        
从用户原句开始，完成无监督发现，再以初版候选体系进行多轮迭代。

        
总流程先用 LLM 分析原子意图，再用 BERTopic 发现类别与层级。明确表达的前置动作也单独保留，例如“打开支付宝，交电费”拆成两条。仅“用支付宝交电费”不补出打开动作。发现过程不读取预制领域、任务或 Skill；拆并建议与候选体系保存在报告中，供确认。
