## 三、建议处理顺序

1. 先消除跨簇复核、叶子提议和复核的全树重复。保留两侧完整路径，向量召回少量父主题；全局背景可用去重的名称概览，并明确精简范围。
2. 独立复核只传选中祖先及必要兄弟摘要、两侧成员和提议，不再把全部候选和整树重新发送。
3. 跨簇样本仅保留intent_id/text，删除重复span/raw_text。
4. 候选任务判断及最终消歧复用紧凑任务描述；减少重复正例、前次长理由，保留真实边界信息。
5. 分组、父级审核和父级重组增加独立的输入预算，区分数量上限和字符/Token上限；超限应按逻辑分批，不静默截断关键语义。
6. S4全目录目前约5千字符，优先级低于十万字符的层级上下文；若改成召回制，应保留目录未覆盖或候选不足的出口。

本次只做审计，未修改请求逻辑、未删除输入，也未执行任何真实模型测试。
