# 升级与历史数据

当前每次流程独立保存分类体系，不再使用全局分类文件。无需复制预制分类体系，运行 `python bootstrap.py` 创建报告、缓存和上传目录即可。

已有 `data/reports/<run_id>/`、样本、上传文件、模型配置和 Prompt 自定义文件可以保留。页面选择流程及其中间结果继续处理，修改层级会创建派生流程并记录来源。

已移除旧版全局分类、汇总、词表归一及维护命令。CLI 使用 `python main.py discover --input input.xlsx --text-column 用户提问`，或通过 `--source`、`--stage` 选择现有流程结果处理。

升级后重启服务并刷新页面。流程不会自动合并或共享分类体系；共享的向量与分类检查点只作为缓存使用。
